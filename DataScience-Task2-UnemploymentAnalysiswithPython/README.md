# Unemployment Analysis with Python

## Oasis Infobyte Data Science Internship – Task 2

### Objective
Analyze unemployment trends in India using Python and identify patterns across different states and regions, including the impact of the COVID-19 period.

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

### Analysis Performed
- Loaded and inspected the unemployment dataset
- Checked dataset shape, columns, and data types
- Cleaned column names and converted the Date column
- Calculated average unemployment rates by region
- Analyzed month-wise unemployment trends
- Visualized unemployment trends for Haryana, Bihar, and Tamil Nadu
- Identified the top 10 regions by average unemployment rate
- Created a correlation heatmap for employment indicators
- Compared unemployment before and during the COVID-19 period
- Documented observations and conclusions from the analysis

### Key Observations
The analysis shows noticeable differences in unemployment rates across regions. The COVID-19 period also resulted in a significant increase in the average unemployment rate compared with the pre-COVID period.

### Files
- `Unemployment_Analysis.ipynb` – Complete Jupyter Notebook containing the analysis, visualizations, observations, and conclusions.
